⚡ Open-Agent-DB CLI Guide

      
Install and run the high-speed local terminal package manager:

      

        

          
# 1. Clone & install CLI

          
git clone https://github.com/open-agent-db/open-agent-db.git

          
pip install -e ./open-agent-db

        

        

          
# 2. Search over 800,000+ assets

          
open-agent search "postgres" --type mcp_server

          
open-agent search "react" --min-stars 50

        

        

          
# 3. 1-Click Install into Claude Code or Codex

          
open-agent install <skill_id> --target claude

        

        

          
# 4. Launch Local Web Explorer (5.6 GB SQLite)

          
open-agent serve --port 8080
